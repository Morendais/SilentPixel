Google Pixel Japanese Camera Mute

Mute the enforced shutter sound on Japanese Pixel phones (Pixel 6/7/8/9/10 series) using the Android Audio Volume Groups API.

Two-line ADB Command:

adb shell "cmd audio set-group-volume 7 0"
adb shell "cmd audio adj-group-volume 7 MUTE"

Quick Instructions:

  1. Enable USB Debugging in Settings > System > Developer Options.
  2. Connect your Pixel to PC/Mac via USB.
  3. Run the commands above (or download mute.bat / mute.sh).
  4. Done! The camera is completely silent, and background music/calls remain completely unaffected.

Note: Android resets audio group volumes upon reboot. Automate on-device using Shizuku + Tasker/MacroDroid to keep it persistent across restarts.
